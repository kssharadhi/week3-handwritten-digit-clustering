For my Week 3 task, I worked on a project called Handwritten Digit Pattern Discovery and Recognition. The main idea was to understand the difference between unsupervised learning, where a model groups data without knowing the correct answers, and supervised learning, where the correct labels are available during training.

I used the handwritten digits dataset included with scikit-learn. It contains 1,797 images of digits from 0 to 9, represented as 8 × 8 pixel values. I first checked sample images and scaled the features. Then I applied K-Means clustering with different numbers of clusters and compared the silhouette scores. I also used Hierarchical Clustering and created a dendrogram to understand how similar images were merged into groups. PCA helped me reduce 64 features to two dimensions for visualization.

In the second part, I evaluated digit recognition with a K-Nearest Neighbors classifier. I used an 80:20 stratified train-test split and 5-fold cross-validation. GridSearchCV tested different values of k to select the best model. I evaluated it using accuracy, confusion matrix, precision, recall, F1-score, and multiclass ROC-AUC.

The selected KNN model used three neighbors and achieved 96.67% accuracy and a macro F1-score of 0.9663 on the test data. The K-Means silhouette score for 10 clusters was only 0.1468, showing that unsupervised groups were less clearly separated. My main learning was that clustering and classification answer different questions, and checking more than one evaluation metric gives a better picture of model performance. I have included the Python code, generated graphs, and actual output files with the report.
